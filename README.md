# Dra. Iasmim Guimarães — site-modelo

Landing page de prospecção criada a partir do portfólio público do Instagram @dra.iasmimguimaraes (Odontologia Estética, Salvador/BA).

- Conceito "Porcelana e Luz": branco-porcelana, verde-sálvia e grafite
- 9 casos reais de facetas, diastema, reabilitação e clareamento, com descrições das legendas dela
- 4 vídeos com som original (novo espaço, confiança dos pacientes, detalhes, Natal na clínica)
- Contato pelo direct do Instagram (nenhum WhatsApp público) + formulário com resumo para copiar
